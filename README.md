# AI-Powered Skin Lesion Classifier

A BTech CSE (AI/ML) project that develops a lightweight computer-vision model for classifying dermatoscopic skin-lesion images into **benign** and **malignant** categories, with a deployable application as the final goal.

> **Medical disclaimer:** This is an educational/research prototype, not a medical device and not a replacement for examination or diagnosis by a qualified healthcare professional.

---
